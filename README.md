# 💰 Personal Finance Manager

Personal Finance Manager es una aplicación web diseñada para ayudar a los usuarios a administrar sus finanzas personales de forma sencilla e intuitiva. Permite registrar ingresos y gastos, organizar movimientos por categorías, establecer presupuestos mensuales y visualizar estadísticas mediante gráficos para obtener un mejor control del dinero.

## ✨ Características

* 🔐 Autenticación de usuarios con JWT.
* 💵 Registro de ingresos y gastos.
* 🗂️ Categorías personalizadas.
* 📊 Dashboard con gráficos y estadísticas.
* 🎯 Presupuestos mensuales.
* 🔍 Búsqueda y filtros avanzados.
* 📄 Exportación de reportes (PDF, Excel y CSV).
* 🌙 Modo oscuro.
* 📱 Diseño responsive.
